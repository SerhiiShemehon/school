Частина 1. Три властивості і чотири межі

width: 300px;         ширина
height: 100px;        висота
font-size: 18px;      розмір тексту
 
min-width: 200px;     «не вужче за»
max-width: 800px;     «не ширше за»
min-height: 100px;    «не нижче за»
max-height: 300px;    «не вище за»

Ширина

  • Задають, коли треба. Блоковий елемент без неї займає всю доступну ширину.
  • На рядкових (span, strong, em, a) не працює — вони займають рівно стільки, скільки треба під вміст.

Висота

  • Майже ніколи не задають. Хай браузер сам підбере під вміст.
  • Задали висоту, а текст виявився довшим — він вилізе за межі блока. Виглядає зламано, а помилки ніде немає.
  • Просте правило: ширину задаємо, коли треба. Висоту лишаємо браузеру.
  • Треба, щоб блок був не нижчим за число, — min-height. Тексту мало — блок рівно стільки, тексту багато — росте. Підлога, а не стеля.

max-width — найкорисніше за урок

body {
  max-width: 800px;
}
  • Читається як «не ширше за». На великому екрані блок зупиниться, на малому стисне себе сам.
  • Чим кращий за width: фіксована ширина на вузькому екрані вилізе за межі, max-width — ніколи.
  • Один рядок у body — і довгий рядок тексту перестає бути проблемою.

Чотири межі

                 ПІДЛОГА              СТЕЛЯ
 
ширина     min-width             max-width
           не вужче за           не ширше за
 
висота     min-height            max-height
           не нижче за           не вище за
  • max-width і min-height — ті, що знадобляться в проекті найчастіше.
  • min-width — щоб кнопка з коротким словом не стала крихітною. Число скромне, інакше на телефоні вилізе.
  • max-height — майже не беруть: довгий текст вилізе, як і з height.
  • Можна разом: min-width: 200px; max-width: 400px;. Мінімум більший за максимум — переможе мінімум.

Розмір тексту

  • 16–18 пікселів для основного тексту. Менше — людина просто не читає.
  • Задайте у body — усе всередині успадкує розмір від батька. Писати кожному тегу не треба.

Частина 2. Чотири одиниці

px    фіксований розмір
      20px — це 20px завжди й усюди
 
%     частка від БАТЬКІВСЬКОГО блока
      width: 50% — половина того,
      у чому блок лежить (не екрана!)
 
em    від розміру тексту ЦЬОГО елемента
      текст 18px → 1em = 18px
      усередині вкладень множиться
 
rem   від розміру тексту ВСІЄЇ сторінки
      не множиться, тому передбачуваний

Головне непорозуміння з відсотками

<div class="outer">      .outer { width: 600px; }
  <div class="inner">    .inner { width: 50%;   }
  </div>
</div>
 
inner вийде 300px — половина outer,
а не половина екрана.

Підступність em

Задали блоку 1.5em, усередині ще один блок і теж 1.5em — виходить не півтора, а два з чвертю. Другий рахується від першого.

rem так не робить ніколи. Коли вагаєтесь між ними — беріть rem.

Частина 3. Що коли брати

  • px — майже завжди. Розміри тексту, ширини, рамки.
  • max-width — для тексту, щоб рядок не розтягувався на весь монітор. Один раз у body.
  • min-height — замість height, коли блок має бути не нижчим за число.
  • % — коли треба саме частку. Знадобиться на уроці 19, для карток у ряд.
  • em і rem — у цьому проекті не обов'язкові. Знайте, що існують, і впізнавайте в чужому коді.

Частина 4. Приклад

Так це виглядає разом. Наберіть руками й підберіть свої числа.

body {
  max-width: 800px;
  font-size: 18px;
}
 
h1 {
  font-size: 40px;
}
 
h2 {
  font-size: 28px;
}
 
.card {
  width: 50%;
}

max-width у body — найважливіший рядок. Саме він робить текст читабельним.

Висоти тут немає навмисно: її не задають. Знадобиться підлога — min-height.

Коли не працює

Задав розмір, а нічого не змінилось

  • Забули одиницю: width: 300 замість width: 300px. Браузер проігнорує мовчки.
  • Виняток — нуль: margin: 0 пишуть без одиниці, і це нормально.

Ширина не застосувалась

  • Перевірте, чи елемент не рядковий. На span, strong, em, a ширина не працює.

Текст виліз за межі блока

  • Ви задали йому height або max-height. Приберіть — хай браузер підбере сам. Потрібна підлога — min-height.

Відсотки дають не те, що я очікував

  • Вони рахуються від батьківського блока, а не від екрана. Подивіться в інспекторі, якої ширини батько.

На вузькому екрані блок вилазить

  • Ви взяли width там, де потрібен max-width.

Застрягли більше ніж на п'ятнадцять хвилин — пишіть у Classroom або на пошту.

Що здати

  • max-width у body — число підберіть самі, щоб читати було зручно.
  • font-size у body: 16 або 18 пікселів.
  • Одному блоку — ширина у відсотках. Звузьте вікно й подивіться.
  • Одним реченням: чим відсотки відрізнились від пікселів.

Перевірятиму: чи є max-width, чи текст не дрібний, чи скрізь є одиниці, чи пояснено різницю.

Висоту не задавайте — тільки min-height. А хочете переконатись чому — задайте height, допишіть у той блок ще два речення й подивіться, що вийде.
